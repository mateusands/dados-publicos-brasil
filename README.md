# Análise de dados

Projetos de análise de dados com Python e pandas, feitos com dados públicos.

| Projeto | Pergunta | Dados |
|---|---|---|
| [enem/](enem/) | Como a nota do ENEM varia por estado, tipo de escola e renda familiar? | Microdados ENEM 2023 (INEP) |

## Ambiente

As dependências são gerenciadas com [uv](https://docs.astral.sh/uv/):

```bash
uv sync               # cria o .venv e instala tudo
uv run jupyter lab    # abre os notebooks
```

Cada projeto tem seu próprio README com os passos para baixar e preparar os dados.
